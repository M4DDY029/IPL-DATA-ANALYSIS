END-TO-END PIPELINE

⚙️ Machine Learning Pipeline & Architecture

How raw Cricsheet JSON deliveries are transformed into predictive intelligence

0

Stage 0: Official Data Ingestion

Cricsheet.org

Downloads and extracts 1,218 match JSON files (~395,000 deliveries across 19 seasons 2008–2026). Parses match metadata, ball outcomes, extras, and dismissals.

1

Stage 1: Data Cleaning & Normalization

Cleaned CSVs

Standardizes team rebranding (e.g. Delhi Daredevils → Delhi Capitals, Kings XI Punjab → Punjab Kings, RCB spelling fixes). Normalizes stadium aliases, strips rain-abandoned ties, and tags over phases (Powerplay: 0–5, Middle: 6–14, Death: 15–19).

2

Stage 2: Lagged Feature Engineering (Zero Leakage)

8 Predictive Features

Computes dynamic pre-match variables strictly on past games: team1_form, team2_form (5-match win rate), form_difference, h2h_team1_win_rate, team1_venue_win_rate, and toss_won_by_team1.

3

Stage 3: Random Forest Classifier (300 Trees)

Model Training

Ensemble of 300 decision trees with max depth 8. Chronological train/test split (first 80% matches = train, last 20% = test). Evaluated on Accuracy, ROC-AUC (0.641), and Log Loss.

4

Stage 4: Real-Time Inference & Dashboard Export

Standalone UI

Exports aggregate tables to IPL_PowerBI_Data.xlsx and provides real-time client-side inference in this interactive web dashboard.
